# Wardrobe

A personal styling app. It plans a week of outfits from clothes I already own, adjusts each morning for the weather in London or Paris, and keeps a log of what I actually wore so neglected pieces come back into rotation.

- **Live:** https://nattyvs.github.io/wardrobe
- **Data:** private repo `nattyvs/wardrobe-private`, connected in the app under Log → Settings with a fine-grained token (contents: read and write on that repo only).
- **Forecast:** Open-Meteo, no key needed.
- **Without data:** the app shows a sample wardrobe, labelled as such.

Plain HTML, CSS and JS. No build step. Fonts are GFS Didot and Jost (SIL Open Font License, see `fonts/`).
